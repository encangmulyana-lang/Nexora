How It Works

  1. Connect wallet (BSC Mainnet, chain 56).
  2. Select mint quantity (max 10 per wallet, lifetime).
  3. Confirm transaction — exactly 0.0001 BNB per NFT + gas.
  4. Open mystery box — the box opens only after the transaction confirms on-chain.
  5. Discover your NFT — tier comes from rarityOf(tokenId) on-chain, never from this page alone.

Binance Agentic Wallet (agent mint)

Agents can mint with the same proof: read totalMinted, take the next tokenId, compute its 13-hash Merkle proof from the published deck, then call mint(proof, rarity) (selector 0x3eee5eb8) with exactly currentPrice(). No Agent ID gate on this contract — any EVM wallet can mint directly.
